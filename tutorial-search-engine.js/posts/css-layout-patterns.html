CSS Layout Patterns

Practical grid, flexbox, spacing, and responsive layout patterns.

Start With a Container

.container {
  width: min(100% - 2rem, 70rem);
  margin-inline: auto;
}

img {
  display: block;
  max-width: 100%;
  height: auto;
}

Use a readable maximum width and let content shrink inside the viewport. This avoids fixed widths that create horizontal scrolling on small screens.

Flexbox for One Dimension

.toolbar {
  display: flex;
  align-items: center;
  justify-content: space-between;
  gap: 1rem;
  flex-wrap: wrap;
}

.toolbar-actions {
  display: flex;
  gap: .5rem;
}

Flexbox is ideal when items flow mainly in a row or column. Use gap for consistent spacing instead of margins between siblings.

Grid for Page Structure

.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(16rem, 1fr));
  gap: 1rem;
}

.dashboard {
  display: grid;
  grid-template-columns: 16rem 1fr;
  min-height: 100vh;
}

@media (max-width: 40rem) {
  .dashboard { grid-template-columns: 1fr; }
}

Use grid when rows and columns matter together. auto-fit lets cards wrap without needing a breakpoint for every screen size.

Responsive Rules

  • Prefer fluid widths, min(), and max() before adding breakpoints.
  • Keep touch targets large enough to activate comfortably.
  • Test long labels and narrow screens, not only ideal content.
  • Use media queries to change layout, not to repair overflow.
  • Check keyboard focus after changing visual order.

Practice Checklist

  • Test layouts with realistic long content.
  • Check keyboard focus after visual changes.
  • Prefer flow layout before absolute positioning.
  • Use consistent spacing tokens.
  • Inspect narrow, wide, and zoomed views.
