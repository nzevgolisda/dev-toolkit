Python Tips & Productivity Patterns

List Comprehensions

Replace verbose loops with concise list comprehensions:

# Traditional approach
squares = []
for x in range(10):
    squares.append(x**2)

# List comprehension
squares = [x**2 for x in range(10)]

# With filtering
even_squares = [x**2 for x in range(10) if x % 2 == 0]

Dictionary Comprehensions

Create dictionaries efficiently:

# Create a dict from two lists
keys = ['a', 'b', 'c']
values = [1, 2, 3]
my_dict = {k: v for k, v in zip(keys, values)}

# Filter and transform
data = {'a': 1, 'b': 2, 'c': 3, 'd': 4}
filtered = {k: v*2 for k, v in data.items() if v > 2}

Context Managers

Use with statements for automatic resource management:

# File handling
with open('file.txt', 'r') as f:
    content = f.read()
# File automatically closed

# Custom context manager
from contextlib import contextmanager

@contextmanager
def timer():
    import time
    start = time.time()
    yield
    print(f"Elapsed: {time.time() - start:.2f}s")

with timer():
    # Your code here
    pass

Unpacking

Multiple assignment and function arguments:

# Basic unpacking
a, b, c = [1, 2, 3]

# Extended unpacking
first, *middle, last = [1, 2, 3, 4, 5]
# first=1, middle=[2,3,4], last=5

# Dict unpacking in function calls
config = {'host': 'localhost', 'port': 8080}
connect(**config)

F-Strings

Modern string formatting (Python 3.6+):

name = "Alice"
age = 30

# Basic f-string
greeting = f"Hello, {name}!"

# With expressions
info = f"{name} is {age} years old, born in {2024-age}"

# Formatting numbers
pi = 3.14159
formatted = f"Pi is approximately {pi:.2f}"

Dataclasses (Python 3.7+)

Create classes for storing data with less boilerplate code.

from dataclasses import dataclass

@dataclass
class User:
    name: str
    email: str
    active: bool = True

user = User("Alice", "alice@example.com")
print(user)  # User(name='Alice', email='alice@example.com', active=True)

Pathlib (Python 3.4+)

An object-oriented way to handle filesystem paths.

from pathlib import Path

# Create a path object
path = Path("/path/to/some/file.txt")

# Access parts of the path
print(path.name)      # 'file.txt'
print(path.stem)      # 'file'
print(path.suffix)    # '.txt'
print(path.parent)    # '/path/to/some'

# Join paths
new_path = path.parent / 'other_file.log'

# Read/write text
path.write_text("Hello, world!")
content = path.read_text()

Useful Built-ins

  • enumerate() - Get index and value in loops
  • zip() - Combine multiple iterables
  • any() / all() - Boolean checks on iterables
  • sorted() - Return sorted list with custom key
  • reversed() - Reverse iteration without modifying

Type Hinting (Python 3.5+)

Improve code clarity and allow for static analysis.

def greet(name: str) -> str:
    return f"Hello, {name}"

from typing import List

def total(numbers: List[float]) -> float:
    return sum(numbers)

Itertools Module

A collection of fast, memory-efficient tools for working with iterators.

import itertools

# Chain multiple iterables together
a = [1, 2]
b = ['x', 'y']
for item in itertools.chain(a, b):
    print(item)  # 1, 2, 'x', 'y'

# Get all possible combinations
for combo in itertools.combinations('ABC', 2):
    print(combo)  # ('A', 'B'), ('A', 'C'), ('B', 'C')

# Get all possible permutations
for perm in itertools.permutations('ABC', 2):
    print(perm) # ('A', 'B'), ('A', 'C'), ('B', 'A'), ('B', 'C'), ('C', 'A'), ('C', 'B')

Virtual Environments

Always use virtual environments for projects:

# Create virtual environment
python -m venv venv

# Activate (Linux/Mac)
source venv/bin/activate

# Activate (Windows)
venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Save dependencies
pip freeze > requirements.txt
