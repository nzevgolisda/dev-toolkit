Quick Open Power User (Ctrl+P)

The "Go to File" menu is more than just a file opener. Use these prefixes to unlock its full power:

(no prefix)   Go to File
@             Go to Symbol in File
@:            Go to Symbol in File by Category
#             Go to Symbol in Workspace
:             Go to Line Number
edt           View active editors
term          View open terminals
>             Access the Command Palette
?             View help

Custom Useful Shortcuts

Add these to your keybindings.json:

[
  {
    "key": "ctrl+shift+7",
    "command": "editor.action.commentLine"
  },
  {
    "key": "ctrl+shift+d",
    "command": "editor.action.copyLinesDownAction"
  },
  {
    "key": "ctrl+k ctrl+c",
    "command": "workbench.files.action.collapseExplorerFolders"
  }
]

Pro Tips

  • Use Ctrl+P then @ to search symbols in current file
  • Use Ctrl+P then # to search symbols in workspace
  • Use Ctrl+P then : to go to line number
  • Use Alt+Click to create multiple cursors quickly
  • Use Ctrl+D repeatedly to select multiple occurrences
  • Use Ctrl+Shift+L to select all occurrences at once
  • Use Ctrl+K Ctrl+S to view all shortcuts and customize them

Tasks

Automate your workflow with tasks. Open the Command Palette (Ctrl+Shift+P) and select "Tasks: Configure Task" to create a tasks.json file.

// .vscode/tasks.json
{
  "version": "2.0.0",
  "tasks": [
    {
      "label": "build",
      "type": "npm",
      "script": "build",
      "problemMatcher": [],
      "group": {
        "kind": "build",
        "isDefault": true
      }
    }
  ]
}

# Run the default build task
Ctrl+Shift+B

Profiles

Profiles let you save and switch between different VS Code configurations (settings, extensions, keybindings, etc.). This is great for separating work and personal setups, or for different programming languages.

Click the gear icon in the bottom-left corner and select "Profiles" to create and manage your profiles.

Practice Checklist

  • Learn shortcuts for actions you repeat daily.
  • Use the command palette to discover commands.
  • Keep project settings local and documented.
  • Review extensions before granting workspace trust.
  • Remove shortcuts that conflict with team habits.
