SQL Essentials

A compact guide to selecting, joining, and safely changing relational data.

Select and Filter

SELECT id, name, created_at
FROM users
WHERE active = TRUE
  AND created_at >= '2026-01-01'
ORDER BY created_at DESC
LIMIT 20;

Choose only the columns you need. Filter before sorting and limiting so the database can reduce the working set early.

Aggregate Results

SELECT department, COUNT(*) AS member_count
FROM employees
GROUP BY department
HAVING COUNT(*) > 3
ORDER BY member_count DESC;

WHERE filters rows before grouping. HAVING filters groups after aggregate functions such as COUNT and SUM have run.

Join Related Tables

SELECT orders.id, users.email, orders.total
FROM orders
JOIN users ON users.id = orders.user_id
WHERE orders.status = 'paid';
  • Use an inner JOIN when both records are required.
  • Use LEFT JOIN when the left record should remain without a match.
  • Join on indexed keys and verify the relationship cardinality.

Change Data Safely

BEGIN;
UPDATE accounts
SET status = 'inactive'
WHERE last_seen_at < '2025-01-01';

SELECT status, COUNT(*)
FROM accounts
GROUP BY status;
COMMIT;

Run the matching SELECT first, use a narrow WHERE clause, and wrap related changes in a transaction when the database supports it.

Practice Checklist

  • Run a select before every data change.
  • Use parameters instead of string-built queries.
  • Inspect query plans for slow operations.
  • Use transactions for related updates.
  • Back up important data before migrations.
