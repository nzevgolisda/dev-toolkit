WSL Quick Setup Guide

Installing WSL2

Run in PowerShell as Administrator:

# Install WSL with default Ubuntu
wsl --install

# Or install specific distro
wsl --install -d Ubuntu-22.04

# List available distributions
wsl --list --online

Restart your computer after installation.

Basic WSL Commands

# List installed distributions
wsl --list --verbose

# Set default distribution
wsl --set-default Ubuntu-22.04

# Start specific distro
wsl -d Ubuntu-22.04

# Shutdown WSL
wsl --shutdown

# Terminate specific distro
wsl --terminate Ubuntu-22.04

# Update WSL
wsl --update

Initial Setup

After first launch, update packages:

# Update package lists
sudo apt update

# Upgrade installed packages
sudo apt upgrade -y

# Install essential tools
sudo apt install -y build-essential git curl wget

Configuring `sudo` without a password

To avoid typing your password for every sudo command, you can add a sudoers file for your user.

# Open the sudoers editor
sudo visudo

# Add the following line at the end of the file, replacing 'username' with your username
username ALL=(ALL) NOPASSWD: ALL

Development Tools

Node.js

# Using NodeSource
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

# Verify installation
node --version
npm --version

Python

# Install Python and pip
sudo apt install -y python3 python3-pip python3-venv

# Verify installation
python3 --version
pip3 --version

Docker

Install Docker Desktop for Windows with WSL2 backend. Then in WSL:

# Verify Docker is accessible
docker --version
docker ps

File System Access

# Access Windows files from WSL
cd /mnt/c/Users/YourUsername/

# Access WSL files from Windows
# In File Explorer: \\wsl$\Ubuntu-22.04\home\username

# Open current directory in Windows Explorer
explorer.exe .

Git Configuration

# Set user info
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"

# Set default branch name
git config --global init.defaultBranch main

# Use Windows credential manager
git config --global credential.helper "/mnt/c/Program\\ Files/Git/mingw64/bin/git-credential-manager.exe"

Useful Tips

  • Store project files in Linux filesystem (~/) for better performance
  • Use Windows Terminal for better WSL experience
  • Install VS Code and use the WSL extension
  • Set up SSH keys for Git authentication

Managing Multiple Distributions

You can have multiple Linux distributions installed at the same time.

# List online distributions
wsl --list --online

# Install another distro
wsl --install -d Debian

# Set the default distro for new terminals
wsl --set-default Ubuntu-22.04

Customization and Productivity

Install a better shell (Zsh + Oh My Zsh)

# Install Zsh
sudo apt install -y zsh

# Install Oh My Zsh
sh -c "$(curl -fsSL https://raw.github.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"

# Set Zsh as your default shell
chsh -s $(which zsh)

Use a terminal multiplexer (tmux)

tmux lets you have multiple terminal sessions in a single window, which is great for running multiple processes at once.

# Install tmux
sudo apt install -y tmux

# Start a new session
tmux

# Learn the keybindings (e.g., Ctrl+b, then % to split vertically)

Backing Up Your Distribution

It's a good practice to back up your WSL distribution, especially before making major changes.

# Export your distribution to a .tar file
wsl --export Ubuntu-22.04 "D:\backups\ubuntu.tar"

# You can later import this backup to a new distribution
wsl --import MyNewUbuntu "D:\wsl\MyNewUbuntu" "D:\backups\ubuntu.tar"

Practice Checklist

  • Keep the distribution and Windows components updated.
  • Store active projects in the fastest filesystem.
  • Use a non-root user for daily work.
  • Test Windows and Linux path boundaries.
  • Back up important distribution data.
