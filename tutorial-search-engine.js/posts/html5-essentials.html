HTML5 Essentials

Semantic structure, forms, and accessible browser features.

Document Structure

<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>Project dashboard</title>
  </head>
  <body>
    <header>Project dashboard</header>
    <main><h1>Recent activity</h1></main>
    <footer>Updated today</footer>
  </body>
</html>

Semantic Landmarks

Use elements for meaning, not appearance. This gives browsers, assistive technology, and search engines a useful page outline.

  • header introduces a page or section.
  • nav groups major navigation links.
  • main contains the page's unique content.
  • section groups a topic with its own heading.
  • article represents independent, reusable content.
  • footer contains closing information and related links.

Accessible Forms

<form>
  <label for="email">Email address</label>
  <input id="email" name="email" type="email" required>
  <button type="submit">Subscribe</button>
</form>

Every control needs a label. Use the input type that matches the data, keep the submit action explicit, and validate on the server as well as in the browser.

Useful Native Elements

  • Use details and summary for expandable content.
  • Use time datetime="2026-08-26" for machine-readable dates.
  • Use figure and figcaption for labelled media.
  • Use dialog for modal interactions that need focus management.

Practice Checklist

  • Give the document one clear main heading.
  • Navigate the page with only the keyboard.
  • Associate every form control with a label.
  • Test content at a narrow viewport.
  • Validate the final document before publishing.
