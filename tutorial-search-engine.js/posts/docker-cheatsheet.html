Docker Cheatsheet

General Commands


docker --version
docker info
docker login
docker logout

Image Management


docker build -t <image_name> .
docker pull <image_name>
docker push <username>/<image_name>
docker images
docker rmi <image_name_or_id>
docker search <term>

Container Management


docker run <image_name>
docker ps
docker ps -a
docker start <container_name_or_id>
docker stop <container_name_or_id>
docker restart <container_name_or_id>
docker kill <container_name_or_id>
docker exec -it <container_name_or_id> <command>
docker logs <container_name_or_id>
docker inspect <container_name_or_id>
docker rm <container_name_or_id>
docker cp <source_path> <container_name>:<destination_path>
docker cp <container_name>:<source_path> <destination_path>

Docker Compose


docker compose up
docker compose down
docker compose ps
docker compose build
docker compose exec <service_name> <command>
docker compose logs <service_name>
docker compose restart <service_name>
docker compose stop <service_name>

Volume Management


docker volume create <volume_name>
docker volume ls
docker volume rm <volume_name>
docker volume prune

Network Management


docker network create <network_name>
docker network ls
docker network rm <network_name>
docker network prune

Cleanup


docker system prune
docker system prune -a
docker image prune
docker image prune -a
docker container prune

Practice Checklist

  • Use a small base image when compatibility allows.
  • Pin important image and dependency versions.
  • Inspect logs before restarting a container.
  • Keep secrets outside images and compose files.
  • Remove unused resources after experiments.
